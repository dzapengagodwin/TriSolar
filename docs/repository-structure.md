# Repository Structure

The **Laptopzone** monorepo uses **Turborepo** workspaces. The top‑level layout is:

```
.
├─ apps/                     # Main applications (backend & storefront)
│  ├─ backend/               # MedusaJS server
│  │   ├─ src/               # Source code
│  │   │   ├─ api/           # File‑based API routes (store/*, admin/*)
│  │   │   ├─ modules/       # Custom Medusa modules (service + models + migrations)
│  │   │   ├─ workflows/     # Business‑logic workflows
│  │   │   └─ subscribers/   # Event subscribers (e.g., order‑placed)
│  │   └─ medusa-config.ts   # DB connection, CORS, secrets
│  └─ storefront/            # Next.js 15 storefront
│      ├─ src/                # Frontend source
│      │   ├─ app/            # App Router entry points (pages, routes)
│      │   ├─ modules/        # Feature modules (store, products, cart, order, wishlist, …)
│      │   │   ├─ store/      # Storefront UI for product listings, filters, pagination
│      │   │   ├─ products/   # Product detail UI, JSON‑LD, SEO components
│      │   │   ├─ cart/       # Cart UI and tracking
│      │   │   ├─ order/      # Checkout & order confirmation UI
│      │   │   └─ wishlist/   # Wishlist UI
│      │   ├─ lib/            # Helpers (cache tags, env utils, API client SDK)
│      │   ├─ styles/         # Global CSS (Tailwind)
│      │   └─ types/          # Shared TypeScript types
│      └─ .env.template        # Environment variables (incl. NEXT_PUBLIC_GA_ID)
├─ docs/                     # Documentation (generated by this assistant)
├─ turbo.json                # Turborepo task graph (dev, build, lint, test)
├─ package.json              # Root package manager config, scripts, workspaces
└─ .gitignore
```

**Purpose of major folders**
- `apps/backend`: The headless commerce engine. Handles data persistence, business rules, and exposes the Medusa REST/SDK API.
- `apps/storefront`: The consumer‑facing UI built with Next.js. All routes are under the App Router (`src/app`).
- `docs/`: All generated documentation lives here; the root `README.md` points to the detailed sections.
- `turbo.json` & `package.json`: Define the monorepo build pipelines and the package manager (`npm@10.9.3`).

**How the parts interact**
- The storefront calls the Medusa backend via the **Medusa JS SDK** (`@medusajs/js-sdk`).
- Both apps share the same workspace configuration, so `npm run dev` (or `npm run backend:dev` / `npm run storefront:dev`) starts them concurrently.
